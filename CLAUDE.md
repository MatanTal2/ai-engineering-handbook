This repo is our team's handbook for working with coding agents. It contains no application code: the deliverable is the process.

Read [handbook/03-cheatsheet.md](handbook/03-cheatsheet.md) before answering any question about which skill or flow to use; it is the index over everything else.

When asked to apply this handbook to another repo, the work is: install the skills, run `/setup-matt-pocock-skills`, and copy [templates/](templates/) into place, adapting `CLAUDE.md` to that repo and deleting every line of it that does not apply. Details in [handbook/00-quickstart.md](handbook/00-quickstart.md).

When editing anything here, follow [handbook/05-writing-skills.md](handbook/05-writing-skills.md). It governs how documents for agents are written, and this repo is made of them. Prose here uses no em-dashes.
